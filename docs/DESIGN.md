# Дизайн-код «Куда на выходных»

Минималистичный Liquid Glass: светлая/тёмная тема по устройству, один акцент (синий), только текстовые кнопки, без эмодзи. Все значения — в `design.css` (раздел «Токены»).

## Принципы
1. **Стекло, а не плоскость.** Поверхности — полупрозрачные (`--glass`) с размытием фона (`backdrop-filter: blur(26px) saturate(180%)`), тонкой светлой рамкой и внутренним бликом сверху. За стеклом — мягкие цветные пятна фона, поэтому оно «живое».
2. **Один акцент.** Синий (`--accent`: #007aff светлая / #0a84ff тёмная). Все кнопки синие: основная — заливка, остальные — полупрозрачный синий с синим текстом.
3. **Минимум управления.** На экране одно главное действие. Остальное — текстовые ссылки синего цвета.
4. **Текст вместо иконок.** Никаких эмодзи и иконок в интерфейсе; единственные графические элементы — шевроны календаря, пятна фона и фото ресторанов.
5. **Тема = устройство.** `prefers-color-scheme`; внутри Telegram — `Telegram.WebApp.colorScheme` (атрибут `data-theme` на `<html>`).

| Группа | Токены |

| Стекло | `--glass`, `--glass-strong`, `--glass-border`, `--glass-line`, `--glass-hi`, `--shadow`, `--blur` |

## Компоненты
- **Строка поиска** (`.search`, `.srow`): стеклянная капсула вверху. Строки добавляются по мере выбора: Даты → Категория → Событие → Ужин. Нажатие на строку возвращает на этот шаг.
- **Календарь** (`.cal`): диапазон выбирается двумя нажатиями; один день — повторное нажатие на ту же дату. Точка под числом — в этот день есть событие.
- **Чип** (`.chip`): выбор категорий, выбранный — синяя заливка. **Сегмент** (`.seg`): фильтры и сортировка.
- **Рулетка** (`.reel-wrap`): вертикальная лента категорий, замедляется и останавливается на выпавшей; результат уходит в шапку.
- **Карточка** (`.card`): категория (синий caps), название, дата · место, теги (язык, цена), «Подробнее» (раскрывает описание), «Источник», пара кнопок «Не нравится / Нравится». Выбранная — синяя рамка, отклонённая — приглушена. Карточка ресторана добавляет фото и описание Google.
- **Нижняя панель** (`.dock`): стеклянная капсула с одним главным действием («Запустить», «Дальше · N»).
- **Кнопки**: `.btn-primary` (заливка), `.btn` (стекло + синий текст), `.btn-quiet` (только текст).

## Сценарий
1. **Даты** — календарь (или «Ближайшие выходные»). После выбора даты уходят в шапку.
2. **Категории** — чипы с числом событий, фильтры «Цена: любая/бесплатно» и «Язык: любой/русский», кнопка «Запустить».
3. **Рулетка** — выпадает одна категория, уходит в шапку, загружается список.
4. **Раунд 1** — «Не нравится / Нравится» по каждой карточке, сортировка (лучшее, дешевле, дороже, по дате), «Дальше · N».
5. **Раунд 2** — из понравившегося выбрать одно: «Иду».
6. **Ужин** — те же два раунда для ресторанов (рейтинг, цена, время пешком, описание и фото Google, ссылка «Открыть в Google»).
7. **Готово** — дата и время событий и ужина, файл `.ics`, Google Calendar.
