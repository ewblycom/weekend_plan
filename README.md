# Куда на выходных · Прага

Раз в день собирает события в Праге и Среднечешском крае, отбирает подходящие паре
из Праги 4 (не туристические), поднимает наверх события на русском и показывает всё
в Telegram Mini App. Тот же сайт открывается и в обычном браузере.

## Как устроено

```
GitHub Actions (каждый день)
  └─ python -m scraper.run
       ├─ prague.eu        ярмарки, выставки, концерты, фестивали, гастро
       ├─ Kudy z nudy      события на ближайшие выходные (Прага + Среднечешский край)
       ├─ Ticket Tailor    русскоязычные концерты и стендап (Spotlight Production)
       └─ Telegram         публичные каналы через t.me/s/<канал>
  → дедупликация → оценка (score.py) → docs/data/events.json → коммит
GitHub Pages раздаёт папку docs/ по HTTPS → её открывает бот в Telegram
```

Постоянные места (боулинг, бильярд, лазертаг, эскейп-румы, мастер-классы) лежат
в `docs/data/places.json` и правятся руками.

## Запуск (один раз, ~15 минут)

1. **Репозиторий.** Создайте приватный или публичный репозиторий на GitHub и загрузите туда эту папку.
   GitHub Pages на бесплатном тарифе работает только для публичных репозиториев.
2. **Pages.** Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/docs`.
   Через минуту сайт будет по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.
3. **Первый сбор.** Actions → *Daily events scrape* → *Run workflow*. Дальше он запускается сам каждое утро.
   Если источник сломался, остальные всё равно соберутся, а внизу приложения будет написано, какой не обновился.
4. **Бот.** В Telegram откройте @BotFather:
   - `/newbot` → имя и username (должен заканчиваться на `bot`), сохраните токен (он здесь не нужен, но не публикуйте его);
   - `/newapp` → выберите бота → название, описание, картинка 640×360 → URL из шага 2;
   - по желанию `/setmenubutton` → тот же URL, чтобы приложение открывалось кнопкой в чате.
   Отправьте ссылку на бота жене: у каждого будет своё избранное ❤️.

## Локально

```bash
pip install -r requirements.txt
python -m pytest -q                          # тесты разбора на сохранённых страницах
python -m scraper.run                        # полный сбор
python -m scraper.run --only prague.eu       # один источник
cd docs && python -m http.server 8000        # открыть http://localhost:8000
```

## Настройка под себя — `scraper/config.py`

- `TELEGRAM_CHANNELS`: добавьте @username русскоязычных каналов-афиш, которые читаете.
  Сейчас там только `czech_info`, точные адреса других каналов я не нашёл.
- `TICKETTAILOR_ORGANIZERS`: другие организаторы русскоязычных событий на Ticket Tailor.
- `TOURIST_MARKERS`, `COUPLE_MARKERS`, `NEAR_HOME`, `CATEGORY_WEIGHT`: что поднимать и что опускать.

## Что важно знать

- Парсеры не завязаны на CSS-классы сайтов, но вёрстка может поменяться. Тогда в
  `events.json → errors` появится «0 событий», а тест или лог Actions подскажет, где именно.
- Бот представляется как `WeekendPragueBot`, соблюдает robots.txt, делает паузу 1,5 с
  между запросами и ходит раз в день. Это личный некоммерческий сбор; если будете
  публиковать выдачу для других людей, сначала прочитайте условия каждого сайта.
- Дата у постов из Telegram берётся из текста и может быть неточной (≈ в карточке).

- **🎲 Подбор** — выбираете даты и категории, жмёте «Крутить»: рулетка выбирает категорию и показывает события.

- **🆓 Бесплатно** и сортировка «Подешевле / Подороже»: цена берётся из текста страницы/поста (`Kč`, `zdarma`, «вход свободный»). Где цены нет — событие уходит в конец при сортировке по цене.
- В Telegram скачивание файла иногда блокируется — тогда откройте сайт в браузере или используйте кнопку Google Calendar.

### Google Places (рестораны с рейтингами)

Рестораны ищутся **вживую из браузера** в момент «Иду» (хранить данные Google на сервере нельзя по их условиям), поэтому нужен ключ:

1. console.cloud.google.com → создать проект → привязать платёжный аккаунт (карту).
2. APIs & Services → Library → включить **Places API (New)**.
3. Credentials → Create credentials → API key. Сразу ограничьте его:
   - *Application restrictions*: **Websites (HTTP referrers)** → `https://ВАШ_ЛОГИН.github.io/*`
   - *API restrictions*: только **Places API (New)**.
4. **Квота**: APIs & Services → Places API (New) → Quotas → поставьте дневной лимит на *Search Nearby* (например, 30/день) и на *Search Text*. Выше лимита Google просто отказывает, деньги не списывает.
5. Billing → Budgets & alerts → бюджет $1 с оповещением на почту.
6. Впишите ключ в `docs/config.js` (`GOOGLE_PLACES_KEY`). Пока он пустой, вместо рейтингов показывается ссылка на Google Maps.

Бесплатно в месяц: 1000 запросов Nearby Search (уровень Enterprise, там рейтинг) и 5000 Text Search (Pro); один «Иду» = по одному запросу каждого типа. Дополнительно в `config.js` стоит `DAILY_REQUEST_CAP` — счётчик в самом приложении.
Фильтры по умолчанию: от 4.3★ и 100+ отзывов, без фастфуда и «еды на вынос», радиус 1,2 км (~15 минут пешком).
